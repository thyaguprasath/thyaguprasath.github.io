# Thyagu Prasath — Portfolio

Personal portfolio site (plain HTML, CSS, JavaScript) with dark/light theme.

## Files
- `index.html` — page content
- `style.css` — styles
- `M_Thyagu_Prasath_Resume.pdf` — add your resume here (the Download resume button links to it)

## Run locally
Open `index.html` in a browser.

## Deploy
Hosted on Netlify. Upload the folder or connect this repo.
